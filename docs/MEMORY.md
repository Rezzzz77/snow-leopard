## ۴. تصمیم‌های ثبت‌شده

### D1 — Local-first
`localStorage` تنها منبع حقیقت. صفر درخواست شبکه.

### D2 — بدون حساب کاربری
نه ایمیل، نه رمز، نه OTP. فقط نام.

### D3 — XP و مرحله برنامه دو مفهوم جدا
- `getStage(xp)` → رشد بصری پلنگ (جوجه→رهبر قله)
- `getHighestUnlockedStage(state)` → مرحله برنامه بازشده
هدر **مرحله برنامه** را نشان می‌دهد؛ کارت پلنگ **مرحله رشد**.

### D4 — ارز «برف» بدون پرداخت
Snowflakes فقط با فعالیت.

### D5 — تفکیک ماژول‌ها
`app.js`=رفتار · `src/db.js`=داده · `src/leopard.js`=موتور · `src/coach.js`=کوچ · `src/theme.js`=رنگ · `src/defaults.js`=محتوا

### D6 — Asset از تصویر مرجع کاربر
`assets/leopard/source.jpg` تصویر پنج‌مرحله‌ای است. `tools/extract_leopard.py` برش می‌زند و پس‌زمینه آبی را **نرم تیره** می‌کند (بدون حذف سخت → بدون حفره). WebP در UI (۱۸–۲۷KB)، PNG fallback.

### D8 — صداها پروسدورال ساخته می‌شوند
`tools/make_audio.py` پنج soundscape را با ریاضی می‌سازد (نویز صورتی/قهوه‌ای،
قطره، موج). هیچ فایل نمونه دانلود نمی‌شود. خروجی WAV → ffmpeg → OGG Opus 24k.
کل حجم صدا: ۴۱۶KB. لوپ بی‌درز با crossfade 2 ثانیه‌ای.

### D9 — i18n ساختار کلید-محور
`src/i18n.js` دیکشنری `fa`/`en` با کلیدهای نقطه‌ای. `applyLocale()` روی
`<html lang dir>` اعمال می‌کند. تست تضمین می‌کند هر کلید فارسی معادل انگلیسی دارد.

### D7 — گراف قطعی
`tools/build_graph.py` بدون timestamp. CI ناهمگامی را رد می‌کند.
