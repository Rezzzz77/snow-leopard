# 🐆 پلنگ برفی — یار هم‌سفر خودمراقبتی

> **«تو مراقبت می‌کنی، او بزرگ می‌شود.»**

اپلیکیشن خودمراقبتی آفلاین‌فیرست با معماری مرحله‌ای، همراه یک **پلنگ برفی** که با قدم‌های کوچک تو رشد می‌کند.

**فارسی · RTL · PWA · بدون حساب کاربری · بدون تلومتری · رایگان**

---

## ✨ چرا این اپ فرق دارد

| | |
|---|---|
| 🔒 **خصوصی به‌معنای واقعی** | هیچ داده‌ای جایی نمی‌رود. `localStorage` تنها محل ذخیره است. صفر درخواست شبکه. |
| 📴 **آفلاین کامل** | Service Worker همه چیز را کش می‌کند. بدون اینترنت هم کار می‌کند. |
| 🪪 **بدون ثبت‌نام** | نه ایمیل، نه رمز، نه شماره. فقط یک اسم (نام مستعار هم کافی است). |
| 🎯 **مرحله‌ای، نه بی‌پایان** | پنج مرحله با معیار عبور مشخص. مرحله بعد فقط با تکمیل قبلی باز می‌شود. |
| 🐆 **همراه بصری** | پلنگ برفی با XP رشد می‌کند: جوجه → نوجوان → جوان → بالغ → رهبر قله. |
| 💰 **صفر هزینه** | GitHub Pages + localStorage. بدون سرویس پولی، بدون API. |

---

## 🚀 اجرا

```bash
git clone https://github.com/Rezzzz77/snow-leopard.git
cd snow-leopard
python3 -m http.server 8080
# سپس http://localhost:8080
```

> `file://` کار نمی‌کند — چون `app.js` از ES Modules استفاده می‌کند.

### دستورها

```bash
npm test                          # تست واحد (۱۱۱ تست)
python3 tools/check_contracts.py  # تست قرارداد HTML ↔ JS
python3 tools/build_graph.py      # بازتولید گراف دانش
python3 tools/extract_leopard.py  # استخراج کاراکتر از assets/leopard/source.jpg
python3 tools/make_audio.py       # تولید صداهای محیطی (ffmpeg لازم)
python3 tools/make_icons.py       # ساخت آیکون‌های PWA
bash tools/backup.sh              # بکاپ: snapshot + کامیت + tag
```

## 🧩 ماژول‌ها

- **اهداف روزانه** — ۵ نوع، ریست شبانه
- **تأمل و ژورنال** — ۶۲ پرامپت فارسی، ۴ تگ، تایپ صوتی (`fa-IR`)
- **زنجیره** — چک‌این روزانه، تعمیر رایگان هر ۷ روز
- **تنفس** — سه الگو (جعبه، ۴-۷-۸، هماهنگ)
- **ردیاب حال** — ۵ سطح + نمودار هفتگی
- **ماجراجویی** — ۳۲ داستان، کشف علاقه/بیزاری
- **کوچ** — اقدام بعدی + انگیزه + درصد پیشرفت (کاملاً لوکال)
- **بینش** — آمار، روند حال، خلاصه هفتگی، پیشنهاد هوشمند
- **ژورنال عمیق** — ۲۰ پرامپت برای خودکاوی
- **عادت‌های بلندمدت** — پیگیری ۲۱ روزه
- **پک نزدیکان** — حداکثر ۵ نفر، بدون فید
- **مأموریت‌ها** — ۱۳ کویست با جایزه برف
- **صداهای محیطی** — ۵ soundscape پروسدورال (برف، باد، آب، موج، سکوت) — ۴۱۶KB کل
- **چندزبانه** — فارسی (RTL) + انگلیسی (LTR)
- **مالکیت داده** — خروجی JSON، ورود، پاک‌سازی کامل

## 🔐 حریم خصوصی

| اصل | پیاده‌سازی |
|-----|-----------|
| Local-first | `localStorage` تنها منبع حقیقت |

| بدون حساب | کاملاً کارا بدون هیچ هویتی |
